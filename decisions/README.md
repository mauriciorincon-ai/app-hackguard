# Architecture decisions (ADR) — index

An ADR is written only for a decision that is **irreversible** or that a later sprint could silently undo (constitution:
`CLAUDE.md`, «ADR solo si la decisión es irreversible»). They are written in English, numbered in order, and never edited to
change what was decided: a new ADR supersedes the old one and the old one keeps its text with the status `superseded`.
`documentos-del-hito.test.ts` fails if a file in this folder is missing from the table below.

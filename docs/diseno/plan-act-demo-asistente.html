Reglas de enfrentamientoRules of engagement

  • Solo se prueba el entorno de pruebas, nunca el de producción.Only the test environment is tested, never production.
  • Nada se prueba contra la infraestructura de terceros.Nothing is tested against third-party infrastructure.
  • Ante un fallo que afecte el servicio, la prueba se detiene y se avisa al dueño.If a failure affects the service, testing stops and the owner is told.
  • Las pruebas del modelo respetan la política de uso del proveedor: solo comportamiento, por la API pública y dentro de los límites.Model tests follow the provider's usage policy: behavior only, through the public API and within limits.

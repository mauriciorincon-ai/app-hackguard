Mapa de equivalenciasEquivalence map

Cuando un marco cambia de versión, sus entradas cambian de número y de nombre. El mapa dice a qué entrada nueva corresponde cada una, para que una prueba o un hallazgo de antes siga apuntando al lugar correcto.When a framework changes version, its entries change number and name. The map says which new entry each one corresponds to, so that an earlier test or finding still points to the right place.

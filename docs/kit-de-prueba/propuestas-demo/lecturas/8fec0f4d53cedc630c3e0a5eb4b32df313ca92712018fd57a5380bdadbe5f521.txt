[Lectura sintética del kit de prueba de HackGuard: no es el texto de la página real.] arXiv 2609.32160. Fourteen checks for evaluating decision models. Abstract. We propose fourteen checks that a team can run before it trusts a model that decides between typed options. Check R3 asks whether every choice was fixed before the test data were opened. A threshold, a prompt or a model picked after looking at the test data inflates the reported performance. Revised v2 (2026-10-01): adds check C5 and renames check T2.
